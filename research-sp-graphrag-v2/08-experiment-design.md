# 实验方案 — SP-GraphRAG

## 总体设计

本研究的实验已在 SP-GraphRAG v7 版本中全部完成。实验结果来自真实运行，非预期设计。

---

## 实验 1: 核心消融实验（6 组对比）

### 目标
验证 H1（结构熵有效性）、H2（检索保持性）、H3（EdgeSchedule 必要性）、H4（跨文档边递减）。

### 数据集
**MultiHop-RAG** (Tang & Yang, 2024)
- 609 篇新闻文章
- 2556 个多跳 QA 对
- 评估采样：200 QA（169 条有效——排除了无法在语料库中找到 ground-truth 的问题）
- 实体规模：13,716 个实体节点，18,044 条关系边

### 基线方法
- **[0] Baseline（SP-GraphRAG 无 EdgeSchedule，λ=0）**: 标准 Leiden 模块度最大化
- **Naive RAG**: TF-IDF 向量检索（chunk-based），作为外部对比

### 实验组

| 组号 | 名称 | EdgeSchedule | λ | 跨文档边 | Path A |
|------|------|:---:|:---:|:---:|:---:|
| [0] | Baseline | ✗ | 0 | ✗ | ✗ |
| [1] | ES only | ✓ | 0 | ✗ | ✗ |
| [2] | Weak constraint | ✓ | 0.001 | ✗ | ✗ |
| [3] | Med constraint | ✓ | 0.003 | ✗ | ✗ |
| [4] | +PathA | ✓ | 0.001 | ✗ | ✓ |
| [5] | +CrossDoc | ✓ | 0.001 | ✓ | ✗ |

### 评估指标
**检索指标（主要）**:
- MRR (Mean Reciprocal Rank)
- P@5 (Precision at 5)
- R@5 (Recall at 5)
- NDCG@10

**社区结构指标（次要）**:
- avg_H: 全局平均结构熵
- 模块度 Q
- 社区数量和层数
- Level-0 物理来源纯净率

### 统计方法
- 单次运行（受限于 LLM API 调用成本）
- 已知局限：169 条 QA 的样本量下，1-2% 的指标差异可能不具备统计显著性

## 实验 2: Naive RAG 外部基线对比

### 目标
将 SP-GraphRAG 与最基本的 Naive RAG 进行对比，评估 GraphRAG 范式在多跳检索上的表现。

### 配置
- Naive RAG: TF-IDF 索引，chunk-based 检索
- SP-GraphRAG: 推荐配置 [3]（λ=0.003, EdgeSchedule, 无跨文档边）

### 已有结果
- Naive RAG: MRR=0.6389, P@5=0.2568
- SP-GraphRAG [3]: MRR=0.4203, P@5=0.1964

**关键发现**: Naive RAG 显著优于当前 GraphRAG 实现（差距约 40%）。这说明当前的 TF-IDF 社区摘要检索策略存在根本性局限，图结构的价值未被充分释放。

| 组 | λ | avg_H | MRR | P@5 | R@5 | NDCG@10 | 层数 |

| [0] Baseline | 0 | 0.0000 | 0.4226 | 0.1964 | 0.2619 | 0.3142 | 3 |
| [1] ES only | 0 | 0.1374 | 0.4206 | 0.1964 | 0.2619 | 0.3131 | 8 |
| [2] Weak | 0.001 | 0.1152 | 0.4211 | 0.1953 | 0.2619 | 0.3134 | 8 |

## 消融分析要点

1. **EdgeSchedule 效果**：[0]→[1]，H 从 0 到 0.1374（生效），检索持平。
2. **λ 约束效果**：[1]→[2]→[3]，H 从 0.1374→0.1152→0.1045（λ 与 H 负相关），检索持平。
3. **Path A 效果**：[2]→[4]，几乎无差异，不推荐。
4. **跨文档边效果**：[2]→[5]，H 从 0.1152→0.1682（增加，符合预期），MRR 下降 1.3%。
5. **推荐配置**：[3] Med constraint — 最低 H（0.1045），P@5 持平。

---

## 风险和已知局限

1. **样本量有限**：169 条有效 QA 下，微小的指标差异（<2%）可能缺乏统计显著性
2. **检索策略限制**：当前使用 TF-IDF 检索，向量检索可能释放更多结构价值
3. **BottomUp 路径 bug**：anchor bonus 因格式不匹配未生效，修复后可能改变结果
4. **单一数据集**：仅在 MultiHop-RAG 上验证，泛化性待证
5. **NER 质量上限**：spaCy 规则式 NER 可能限制了实体抽取质量
