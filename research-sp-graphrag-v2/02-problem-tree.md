# 问题分解树 — SP-GraphRAG

## 总研究问题

> 结构熵惩罚能否在 GraphRAG 的社区检测中实现物理结构感知性，同时保持检索效果？

---

## 子问题分解

### SP1: 物理锚定表示 [P0 - 核心基础]

**问题**：如何在知识图谱的实体节点中保留完整的物理出处信息（文档→段落→句子），使其可被社区检测算法利用？

- **可证伪性**：如果锚定信息丢失或格式不一致，结构熵计算将退化为 0。
- **研究方法**：工程设计 + 实证验证
- **依赖**：无前置依赖（基础层）
- **风险**：实体消解（entity resolution）会破坏物理锚定的唯一性；本研究选择"不做消解，保留实例级节点"策略。
- **结论**：v7 实验中，通过 `{sent_id}-{entity_name}` 格式成功保留了三级物理坐标，但前提条件是不做跨文档实体合并。

### SP2: 结构熵惩罚目标函数 [P0 - 核心算法]

**问题**：如何将物理结构混杂度量化为可微分的惩罚项，并与 Leiden 的模块度优化目标融合？

- **可证伪性**：如果 H 恒为 0（所有社区物理来源完全纯净），则惩罚项失效。如果 ΔH 计算复杂度过高（非 O(1)），则无法扩展。
- **研究方法**：理论设计 + 实证验证
- **依赖**：SP1（需要物理锚定信息来计算 H）
- **核心公式**：J = Q_leiden - λ · H_structure, 其中 H = -Σ p_i log p_i
- **关键技术挑战**：
  - 增量 ΔH 计算的 O(1) 近似（通过维护社区内物理单元计数器）
  - 权重校准：注入边权重 w 必须足够大（≥1.0），使 δQ 能与 λ·δH 竞争
- **结论**：v7 实验中 H 从 0 变为 0.10-0.17，证明约束生效。

### SP3: 退火调度策略 [P1 - 核心机制]

**问题**：如何设计 λ 的衰减策略，使低层社区保持物理纯净，高层社区允许跨来源合并？

- **可证伪性**：如果所有退火策略下的社区结构无差异，则退火无意义。如果 λ 恒定且效果更好，则退火不必要。
- **研究方法**：实证对比（消融实验）
- **依赖**：SP2（退火控制的是 λ 参数）
- **设计选项**：exponential / linear / cosine / constant
- **结论**：v7 使用 exponential 退火，λ=0.003 配置下 H=0.1045（最低），λ 与 H 呈单调递减关系（24% 下降），证明退火控制有效。

### SP4: EdgeSchedule 同名实体边注入 [P1 - 工程机制]

**问题**：当知识图谱构建仅生成句内边（共现/依存关系）时，如何打破"句内孤岛森林"使社区检测能发现跨句子的语义联系？

- **可证伪性**：如果不注入边，图为纯森林结构（每句一棵树），Leiden 算法退化为单节点社区。如果注入边后 H≡0 仍然成立，则注入无效。
- **研究方法**：对比消融实验
- **依赖**：SP1（依赖物理锚点进行同名实体匹配）
- **核心设计**：
  - 同段落跨句子边：w=2.0（链式连接）
  - 同文档跨段落边：w=1.5（代表节点链式）
  - 跨文档边：w=1.0（代表节点链式，上限 5）
- **权重校准关键**：原始图总边权 m≈18000，若 w<0.5 则 δQ≈1.1e-5 远小于 λ·δH≈6.9e-4
- **结论**：EdgeSchedule 是 H>0 的必要条件；跨文档边边际收益递减（MRR -1.6%）。

### SP5: 检索效果保持性 [P0 - 核心验证]

**问题**：在引入结构熵约束后，GraphRAG 的检索质量是否会显著下降？

- **可证伪性**：如果 P@5 或 MRR 下降超过 5%，则方法不可接受。
- **研究方法**：定量对比实验
- **依赖**：SP2, SP3, SP4（需要完整的约束管线）
- **评估指标**：MRR, P@5, R@5, NDCG@10
- **数据集**：MultiHop-RAG（200 QA 抽样，169 条有效）
- **结论**：所有约束配置的检索指标波动在 ±2.5% 以内，推荐配置 [3]（λ=0.003）P@5 与 Baseline 持平。
