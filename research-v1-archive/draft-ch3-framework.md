# 第3章 研究框架

## 3.1 问题形式化

本章提出 PhysAnchor-GraphRAG 框架的完整技术方案。在展开具体设计之前，首先对研究问题进行形式化定义，明确输入、输出、优化目标以及核心符号体系。

**输入。** 设专业领域文档集合为 $D = \{d_1, d_2, \ldots, d_M\}$，其中每篇文档 $d_l$ 具有显式的物理层级结构。具体而言，文档 $d_l$ 由有序章节序列 $d_l = \langle s_{l,1}, s_{l,2}, \ldots, s_{l,|S_l|} \rangle$ 组成，其中 $s_{l,k}$ 表示文档 $d_l$ 的第 $k$ 个章节。每个章节 $s_{l,k}$ 进一步由文本块序列 $s_{l,k} = \langle c_{l,k,1}, c_{l,k,2}, \ldots, c_{l,k,|C_{l,k}|} \rangle$ 组成，其中 $c_{l,k,j}$ 为经过切分后的第 $j$ 个文本块（Chunk）。文档集合中文本块的总数记为 $N_c = \sum_{l,k} |C_{l,k}|$，章节总数记为 $N_s = \sum_l |S_l|$。

**输出。** 给定用户查询 $q$，系统需要生成两个输出：（1）回答文本 $a$；（2）溯源集合 $S_q = \{(c_j, s_k, d_l)\}$，其中每个三元组表示回答 $a$ 中某一事实断言所源自的文本块 $c_j$、章节 $s_k$ 和文档 $d_l$。溯源集合 $S_q$ 为使用者提供从宏观到微观的三级证据追溯路径。

**核心优化目标。** 本研究追求的并非单一指标的极致优化，而是在三个目标之间寻求帕累托均衡：

$$
\max_{\theta} \; \text{Macro-Quality}(\theta) \quad \text{s.t.} \quad \text{Micro-Accuracy}(\theta) \geq \tau_1, \quad \text{Token-Cost}(\theta) \leq \tau_2
$$

其中 $\theta$ 为框架的全部可调参数，$\text{Macro-Quality}$ 衡量跨文档综合问答的全面性与多样性（对应 GraphRAG 的核心优势），$\text{Micro-Accuracy}$ 衡量微观事实问题的回答准确率与溯源精度，$\text{Token-Cost}$ 为查询阶段的大语言模型调用消耗。约束 $\tau_1$ 和 $\tau_2$ 的含义是：微观准确率应逼近直接方案（将全部文档逐段输入 LLM）的水平，同时 token 消耗应远低于直接方案。这一三元目标的平衡正是 PhysAnchor-GraphRAG 的设计核心。

**关键符号表。** 为便于后续叙述，此处统一定义本章使用的核心符号：

- $G = (V, E)$：知识图谱，其中 $V$ 为实体节点集合，$E$ 为关系边集合
- $\text{anchor}(e)$：三元组或节点 $e$ 的物理锚点集合，每个锚点为三元组 $(c_j, s_k, d_l)$
- $C = \{C_1, C_2, \ldots, C_K\}$：社区划分结果，$K$ 为社区数
- $Q_{\text{Leiden}}(C)$：标准 Leiden 模块度目标函数值
- $H_{\text{structure}}(C)$：社区划分的物理结构熵
- $J(C; \lambda)$：退火聚类目标函数，$J = Q_{\text{Leiden}} - \lambda \cdot H_{\text{structure}}$
- $\lambda(t)$：退火调度函数，$\lambda(t) = \lambda_0 \cdot e^{-\alpha t}$
- $P_k$：社区 $C_k$ 中节点的 Section 分布概率向量

## 3.2 框架总览

PhysAnchor-GraphRAG 的整体架构由四个阶段组成，形成从文档输入到带溯源回答输出的完整管线。下图以 ASCII 架构图展示了四个阶段及其内部组件，其中 ★ 标注的组件为本研究的核心创新，其余为工程集成或沿用已有方法的模块。

```
┌─────────────────────────────────────────────────────────┐
│                    PhysAnchor-GraphRAG                    │
│                                                           │
│  ┌──────────────────┐   ┌──────────────────┐             │
│  │ 阶段1：文档预处理  │   │ 阶段2：图构建      │            │
│  │ 文档解析          │──→│ 命题转换          │            │
│  │ 物理结构识别      │   │ 实体/关系抽取     │            │
│  │ Chunk切分         │   │ ★物理锚挂载       │            │
│  └──────────────────┘   └────────┬─────────┘             │
│                                  │                       │
│                                  ↓                       │
│  ┌──────────────────────────────────────────┐            │
│  │ 阶段3：★结构熵约束退火聚类                  │           │
│  │ J = Q_Leiden − λ(t)·H_structure            │           │
│  │ H_structure = 香农熵(Section分布)           │           │
│  │ λ(t) = λ₀·e^{-αt} (指数退火)              │           │
│  │ → 层级社区 + 社区摘要                       │           │
│  └────────────────────┬─────────────────────┘            │
│                       │                                   │
│                       ↓                                   │
│  ┌──────────────────────────────────────────┐            │
│  │ 阶段4：U型双轨检索（工程集成）              │           │
│  │ 自上而下：社区摘要匹配 → 范围锁定           │           │
│  │ 自下而上：节点匹配 → ★物理锚追溯 → Chunk   │           │
│  │ 融合策略 → LLM生成 + 溯源集合              │           │
│  └──────────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────┘
  ★ = 本研究的创新组件
```

**阶段1：文档预处理。** 此阶段将原始文档集合 $D$ 转化为结构化的文本块序列。首先通过文档解析器识别每篇文档的物理层级结构（标题、章节、段落），建立文档-章节-段落的三级树形索引。随后，按照固定窗口（默认 300 tokens）对每个章节内的文本进行切分，生成文本块集合。关键的是，每个文本块 $c_j$ 在生成时即被标记其所属的章节 $s_k$ 和文档 $d_l$，形成初始的物理坐标 $(c_j, s_k, d_l)$。这一阶段为后续的物理锚定机制奠定数据基础。

**阶段2：图构建与物理锚挂载。** 此阶段将文本块转化为知识图谱 $G = (V, E)$。首先，借鉴 Dense X Retrieval [6] 的命题转换方法，将每个文本块分解为原子化、自包含的命题单元。随后通过大语言模型对命题进行实体识别和关系抽取，构建初始知识图谱。在这一过程中，★物理锚挂载作为本研究的创新组件被嵌入：每个三元组在生成时继承其来源命题的物理坐标，当多源实体合并为同一节点时，合并节点保留所有来源锚点的并集。物理锚挂载是纯元数据操作，不增加任何 LLM 调用，不引入新的图节点，也不改变图的拓扑结构。

**阶段3：★结构熵约束退火聚类。** 此阶段是本研究的核心算法创新。标准 GraphRAG [1] 使用 Leiden 算法 [7] 对知识图谱进行社区检测，优化纯拓扑目标函数 $Q_{\text{Leiden}}$。本研究修改目标函数为 $J = Q_{\text{Leiden}} - \lambda(t) \cdot H_{\text{structure}}$，其中 $H_{\text{structure}}$ 为基于香农熵 [8] 的物理结构混杂度度量，$\lambda(t) = \lambda_0 \cdot e^{-\alpha t}$ 为指数退火调度函数。退火过程实现了从早期的物理结构保护到后期的语义自由连接的平滑过渡。聚类完成后，对每个社区生成摘要，形成层级化的社区-摘要索引。

**阶段4：U型双轨检索（工程集成）。** 此阶段直接借鉴 MedGraphRAG [3] 的 U-Retrieval 范式和 HiRAG [13] 的层级检索策略，不构成本文的创新贡献。检索过程由两条路径协同完成：自上而下路径从社区摘要出发，通过语义匹配锁定目标社区的范围；自下而上路径从实体/关系节点出发，通过物理锚追溯到原始文本块，实现 $O(1)$ 精确溯源。两条路径的检索结果经加权融合后输入 LLM 生成最终回答，同时输出溯源集合 $S_q$。

四个阶段之间的数据流和依赖关系是单向的：阶段1的输出（结构化文本块）流入阶段2，阶段2的输出（带锚点的知识图谱）流入阶段3，阶段3的输出（层级社区划分与摘要）与阶段2的图结构共同流入阶段4。这一串行管线设计保证了物理锚信息在全链路中的完整传播——这正是3.3节将要详细论证的关键性质。

## 3.3 物理锚定机制（★创新1）

物理锚定机制是 PhysAnchor-GraphRAG 的基础性创新。其核心思想是：为知识图谱中的每一个信息元素（三元组、实体节点、社区节点）附加一组不可丢失的物理出处坐标，使得无论图结构经历何种变换（实体合并、社区聚合、层级压缩），任意信息元素都能在 $O(1)$ 时间内追溯到其在原始文档中的精确位置。

### 3.3.1 三级物理锚点定义

**定义 1（物理锚点）。** 对于知识图谱中的任意信息元素 $e$（三元组、实体节点或社区节点），其物理锚点集合定义为：

$$
\text{anchor}(e) = \{(c_j, s_k, d_l) \mid \text{三元组}\ e\ \text{的信息源自文档}\ d_l\ \text{的章节}\ s_k\ \text{中的文本块}\ c_j\}
$$

其中三元组 $(c_j, s_k, d_l)$ 的三个分量分别对应文本块级（Chunk）、章节级（Section）和文档级（Document）三个物理粒度。这一三级设计的动机在于：文本块级提供最精细的事实定位，章节级提供因果上下文的边界，文档级提供全局来源标识。三级粒度共同构成从微观到宏观的溯源路径。

需要特别强调的是，物理锚点是纯元数据挂载操作，具有三个"不"的性质：不增加 LLM 调用（锚点信息在文档预处理阶段即可确定）；不引入新的图节点或边（锚点存储为节点的属性字段而非独立实体）；不改变图的拓扑结构（锚点的存在与否不影响节点间的连接关系）。这三个性质保证了物理锚定机制的零边际推理成本特性。

### 3.3.2 命题转换中的锚点继承

在图构建阶段，原始文本块 $c_j$ 首先经过命题分解（Proposition Transfer）[6] 生成一组原子化命题 $\{p_1, p_2, \ldots, p_n\}$。每个命题 $p_i$ 是一个自包含的事实陈述，满足"去上下文化"条件——即脱离原始段落仍可独立理解。命题分解是 Dense X Retrieval [6] 提出的知识粒度优化方法，已被 NodeRAG [26] 等后续工作广泛采纳。

在命题分解过程中，物理锚点按照以下继承规则传播：

**规则 1（命题锚点继承）。** 若命题 $p_i$ 由文本块 $c_j$ 分解而来，则：

$$
\text{anchor}(p_i) = \text{anchor}(c_j) = \{(c_j, s_k, d_l)\}
$$

即命题 $p_i$ 完整继承其来源文本块的物理锚点。由于每个命题源自且仅源自一个文本块，继承关系是一对多的确定性映射（一个文本块可生成多个命题，但每个命题只有一个来源文本块），因此继承规则不存在歧义。

随后，对命题集合进行实体识别和关系抽取，将每个命题转化为一组三元组 $(h, r, t)$（头实体、关系、尾实体）。三元组同样继承其来源命题的物理锚点：若三元组 $(h, r, t)$ 从命题 $p_i$ 中抽取，则 $\text{anchor}((h, r, t)) = \text{anchor}(p_i)$。这一继承链确保了从原始文本到知识图谱的物理溯源信息不在任何环节断裂。

### 3.3.3 实体合并中的多源锚点保留

在知识图谱构建过程中，同一实体可能在不同文档的不同章节中被多次提及，形成多个独立的实体节点。实体对齐（Entity Resolution）阶段需要将这些重复节点合并为单一节点。合并操作是物理锚点面临的第一个挑战：如何在合并后保留所有来源的溯源信息？

**规则 2（合并锚点并集）。** 当多个来源的实体被合并为同一节点 $v$ 时，合并节点的锚点集合取所有来源锚点的并集：

$$
\text{anchor}(v) = \bigcup_{e \in \text{sources}(v)} \text{anchor}(e)
$$

其中 $\text{sources}(v)$ 为合并前所有指向同一实体的节点集合。例如，若实体"白细胞介素-6"分别在文档 $d_1$ 的"方法"章节和文档 $d_3$ 的"结果"章节中被提及，则合并后的节点 $v$ 的锚点集合包含这两个来源的物理坐标：$\text{anchor}(v) = \{(c_{12}, s_{1,2}, d_1),\ (c_{47}, s_{3,4}, d_3)\}$。

**空间复杂度分析。** 合并操作导致的锚点集合膨胀是需要评估的工程关注点。设知识图谱中共有 $|V|$ 个节点，平均每个节点由 $\bar{m}$ 个来源实体合并而成，每个锚点三元组存储 3 个 ID 字段（假设每个 ID 为 32 位整数，共 12 字节）。则锚点元数据的总存储开销为 $|V| \cdot \bar{m} \cdot 12$ 字节。在典型的专业领域知识图谱中，$\bar{m}$ 的中位数通常为 1-3（大多数实体仅在少数文档中出现），少数高频实体（如疾病名称、通用法律术语）的 $\bar{m}$ 可达 10-20。据此估算，锚点元数据的额外存储开销约为原始图结构存储量的 15%-25%，这一开销在工程上是完全可接受的。

### 3.3.4 物理锚在图结构演化中的传播保证

物理锚定机制的核心价值在于其全链路传播保证：无论知识图谱经历何种结构变换，物理锚信息只增不减。这一性质是溯源完整性的理论基础，下面以命题形式给出形式化陈述和证明。

**命题 1（锚点传播单调性）。** 对于任意图变换操作 $T$（包括但不限于实体合并、社区合并、层级压缩），若输入图 $G$ 中信息元素 $e$ 具有锚点集合 $\text{anchor}(e)$，则输出图 $T(G)$ 中对应元素 $e'$ 的锚点集合满足：

$$
\text{anchor}(e) \subseteq \text{anchor}(e')
$$

**证明。** 对三类图变换操作分别验证。

情形一：实体合并。设节点 $v_1, v_2, \ldots, v_n$ 被合并为节点 $v'$。根据规则2，$\text{anchor}(v') = \bigcup_{i=1}^n \text{anchor}(v_i)$。对于任意 $v_i$，显然 $\text{anchor}(v_i) \subseteq \bigcup_{i=1}^n \text{anchor}(v_i) = \text{anchor}(v')$，单调性成立。

情形二：社区合并。设社区 $C_k$ 中包含节点集合 $\{v_1, v_2, \ldots, v_{|C_k|}\}$，社区被聚合为超节点 $u_k$ 时，定义 $\text{anchor}(u_k) = \bigcup_{v \in C_k} \text{anchor}(v)$。对于任意 $v \in C_k$，$\text{anchor}(v) \subseteq \text{anchor}(u_k)$，单调性成立。

情形三：层级压缩。层级压缩是社区合并的递归应用——将底层社区的超节点进一步聚合为更高层的超节点。由情形二的结论和集合并运算的结合律，递归应用后单调性仍然成立。

综合三种情形，命题1得证。 $\square$

命题1的实际意义是：在 PhysAnchor-GraphRAG 的全部处理管线中，从文本块经命题分解、实体抽取、实体合并、社区聚类到层级压缩的每一步，物理锚信息都只会增加或保持不变，绝不会丢失。这为检索阶段的 $O(1)$ 精确溯源提供了理论保障——无论查询命中的是底层实体节点还是高层社区摘要节点，都可以通过其锚点集合直接定位到原始文本块，无需额外的模糊匹配或反向搜索。

## 3.4 结构熵约束退火聚类算法（★创新2）

结构熵约束退火聚类是 PhysAnchor-GraphRAG 的核心算法创新。其核心思想是：在 Leiden 社区检测的目标函数中引入一个基于物理锚点分布的结构熵惩罚项，通过退火调度机制动态控制物理结构约束的强度，实现从早期的物理一致性保护到后期的跨文档语义连通的平滑过渡。

### 3.4.1 标准 Leiden 的局限性分析

Leiden 算法 [7] 是 GraphRAG [1] 的默认社区检测方法，其优化目标为模块度函数 $Q$ 或常量 Potts 模型（CPM）。以模块度为例，标准 Leiden 优化的目标函数为：

$$
Q_{\text{Leiden}}(C) = \frac{1}{2m} \sum_{k=1}^K \sum_{i,j \in C_k} \left( A_{ij} - \frac{d_i d_j}{2m} \right)
$$

其中 $A_{ij}$ 为邻接矩阵元素，$d_i$ 为节点 $i$ 的度数，$m$ 为总边数。这一目标函数是纯拓扑的——它仅依赖于节点间的连接关系，对节点的任何外部属性（包括其物理来源）完全不感知。

这种"拓扑盲目性"在专业领域知识图谱中会导致具体的结构破坏。考虑一个典型场景：某篇医学文献的"方法"章节包含 10 个高度因果关联的事实节点（如实验设计的各步骤和条件），这些节点之间存在密集的关系边。然而，其中 3 个节点（如涉及特定药物的剂量信息）与其他文献中讨论同一药物的节点也存在较强的拓扑连接。标准 Leiden 在优化模块度时，可能将这 3 个节点"拉入"由其他文献节点主导的社区，从而打碎了原始章节内的因果链。打碎的后果是：当用户查询该实验的具体条件时，社区摘要中只能提供不完整的片段，无法还原完整的实验设计逻辑。

ArchRAG [24] 明确诊断了 Leiden 的这一缺陷，指出"Leiden 忽略节点和边的语义信息导致社区主题混杂"。但 ArchRAG 选择了高成本的 LLM 路线——通过大语言模型对每次社区划分决策进行语义审核，其索引阶段的 LLM 调用量显著增加。本研究提出另一条路径：不替换 Leiden 算法本身，而是通过修改其目标函数引入物理结构约束，以零 LLM 额外成本实现结构保护。

### 3.4.2 物理结构熵 $H_{\text{structure}}$ 的定义

为量化社区划分中物理来源的混杂程度，本研究基于香农熵 [8] 定义物理结构熵。

**定义 2（物理结构熵）。** 给定聚类结果 $C = \{C_1, C_2, \ldots, C_K\}$，物理结构熵定义为：

$$
H_{\text{structure}}(C) = \sum_{k=1}^{K} \frac{|C_k|}{N} \cdot H(P_k)
$$

其中 $N = |V|$ 为节点总数，$|C_k|$ 为社区 $C_k$ 的节点数，$P_k = (p_{k,1}, p_{k,2}, \ldots, p_{k,|S_k|})$ 为社区 $C_k$ 中节点的 Section_ID 分布概率向量。具体而言，$p_{k,i}$ 表示社区 $C_k$ 中来自第 $i$ 个章节的节点所占比例，$|S_k|$ 为社区 $C_k$ 中出现的不同章节数目。$H(P_k)$ 为概率向量 $P_k$ 的香农熵：

$$
H(P_k) = -\sum_{i=1}^{|S_k|} p_{k,i} \cdot \log(p_{k,i})
$$

$H_{\text{structure}}$ 的直觉含义十分清晰：当一个社区中的所有节点均来自同一个章节时，$P_k$ 为退化分布（仅一个分量为 1），此时 $H(P_k) = 0$；当社区中的节点均匀地来自多个不同章节时，$H(P_k)$ 达到最大值 $\log(|S_k|)$。因此，$H_{\text{structure}}$ 越大意味着社区内来自不同章节的节点越混杂，$H_{\text{structure}}$ 越小意味着社区内节点的物理来源越一致。

**选择香农熵而非 Rényi 熵的理由。** Li 与 Pan [8] 在结构熵的理论框架中建立了信息论与社区检测之间的深层联系，CoDeSEG [9] 进一步在博弈论框架下验证了结构熵作为社区检测目标函数的有效性。在可供选择的信息熵度量中，Rényi 熵 [17] 作为香农熵的参数化推广（$H_\alpha(P) = \frac{1}{1-\alpha} \log \sum_i p_i^\alpha$，$\alpha \to 1$ 时退化为香农熵）提供了更丰富的分布刻画能力。然而，本研究选择香农熵基于三个理由：其一，可解释性——$H(P_k) = 0$ 精确对应"社区完全来自单一章节"，这一语义在专业领域中具有直接的物理意义；其二，计算效率——香农熵的计算复杂度为 $O(|S_k|)$，无额外超参数需要调优；其三，简洁性——引入 Rényi 熵的参数 $\alpha$ 将与退火系数 $\lambda$ 形成双参数交互，增加调优复杂度但未必带来显著收益。Rényi 熵作为 $H_{\text{structure}}$ 的参数化替代方案，是一个值得探索的未来扩展方向。
