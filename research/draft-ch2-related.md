# 第2章 相关工作

本章从六个维度系统梳理与 PhysAnchor-GraphRAG 相关的研究基础与前沿进展，包括检索增强生成的演进脉络、面向专业领域的 GraphRAG 变体、检索策略的迭代演化、Leiden 聚类与社区检测的理论扩展、命题级检索粒度的研究，以及 RAG 忠实性与溯源评估的现状。在每个子领域的梳理中，我们着重分析已有工作与本研究之间的联系与差异，以明确 PhysAnchor-GraphRAG 的差异化定位。

## 2.1 检索增强生成（RAG）

检索增强生成（Retrieval-Augmented Generation, RAG）范式的提出标志着大语言模型知识获取方式的一次范式转变。Lewis 等人 [4] 首次将预训练的参数化记忆（序列到序列 Transformer）与非参数化记忆（基于维基百科的密集向量索引）相结合，通过在生成过程中动态检索相关文档来增强模型的知识能力。这一工作奠定了 RAG 的基本架构：检索器负责从外部知识源中召回相关证据，生成器则以检索结果为条件产出最终回答。RAG 的核心优势在于其非参数化记忆的可替换性——无需重新训练模型即可更新知识来源，这使得 RAG 成为弥补大语言模型知识局限性的主流范式。

随着 RAG 研究的深入，该领域经历了从简单到复杂的持续演进。Gao 等人 [5] 在其综述中系统梳理了这一演进路径：早期的 Naive RAG 采用简单的检索拼接策略，面临检索质量低和生成一致性差的瓶颈；Advanced RAG 引入查询改写、检索重排序和上下文压缩等优化策略，显著提升了端到端性能；Modular RAG 进一步将检索、组织、生成和评估等环节模块化，支持灵活的管线编排。然而，上述三个阶段均基于扁平的文本检索范式，难以有效捕捉实体间的结构化关系和跨文档的全局语义。

Graph RAG（图增强检索生成）的提出代表了 RAG 范式的又一次质变。Edge 等人 [1] 提出的 GraphRAG 框架通过大语言模型从源文本中抽取实体和关系以构建知识图谱，随后使用 Leiden 社区检测算法对知识图谱进行多层级社区划分，并为每个社区生成语言模型摘要，最终通过 map-reduce 策略聚合社区摘要来回答全局性查询。这一方法在 Comprehensiveness（全面性）和 Diversity（多样性）两个指标上显著优于 Naive RAG，证明了图结构化索引对于全局性知识组织的关键价值。GraphRAG 的核心管线可以概括为五个阶段：实体与关系抽取、知识图谱构建、Leiden 层级聚类、社区摘要生成、以及基于社区层级的检索与生成。

围绕 GraphRAG 这一新兴范式，多项综述工作对其进行了系统化的理论梳理。Fan 等人 [2] 提出了 GraphRAG 的统一五组件框架，将其分解为查询处理器（Query Processor）、检索器（Retriever）、组织器（Organizer）、生成器（Generator）和数据源（Data Source）五个功能模块，并系统分析了基于图的索引、图引导的检索和图增强的生成三个核心技术阶段。面向定制化大语言模型的 GraphRAG 综述 [22] 进一步从复杂查询理解、跨源知识整合和大规模系统效率三个挑战维度审视了 GraphRAG 在不同专业领域的应用现状，指出索引构建中的 LLM 调用成本是阻碍大规模部署的主要瓶颈。

本研究以 GraphRAG [1] 的 Leiden 层级社区架构为直接基座，在其核心管线的聚类阶段引入物理结构约束，在图构建阶段增加物理锚定机制。从 Fan 等人 [2] 的五组件框架视角来看，PhysAnchor-GraphRAG 的创新集中在索引阶段的组织器（Organizer）层面——通过目标函数的算法级修改而非增加 LLM 调用来提升索引质量，这一路径在现有综述所梳理的方法空间中尚属未被充分探索的方向。

## 2.2 专业领域GraphRAG

通用 GraphRAG 框架在开放域问答中表现出色，但专业领域对知识检索提出了更高的要求——药物剂量必须精确无误、法条编号不容混淆、实验参数需要严格溯源。为此，多项研究从不同维度探索了 GraphRAG 的领域适配策略。

在医学领域，MedGraphRAG [3] 提出了迄今最具影响力的专业领域 GraphRAG 方案。其核心创新在于三重图构建（Triple Graph Construction）——将用户上传的医学文档、权威医学知识库（如 MedlinePlus）和受控医学词表（如 UMLS）三类来源在同一知识图谱中显式链接，使大语言模型能够区分个人数据与权威参考资料，从而在安全性要求极高的医学场景中生成更可靠的回答。MedGraphRAG 同时提出了 U-Retrieval 技术，实现了自上而下从全局文档图到局部三元组的层级检索，显著减少了需要送入 LLM 的上下文量。该工作在 PubMedQA 等多个医学问答基准上达到了领先水平，并被 ACL 2025 收录为长文。然而，MedGraphRAG 对 UMLS 等外部受控词表的强依赖限制了其向非医学领域的迁移能力，且三重图构建阶段的大量 LLM 调用带来了较高的索引成本。

在法律领域，SAT-Graph RAG [19] 提出了一种本体驱动的层级与时序感知框架。该工作深刻认识到法律文档具有严格的物理层级结构（法典→篇→章→条→款→项），并通过显式建模法律规范的形式结构和历时性特征（时间有效性、修订历史），在知识图谱中同时编码结构维度和时间维度。SAT-Graph RAG 的实践验证了一个关键论断：文档的物理组织结构在专业领域中承载着不可替代的语义信息。然而，其对法律领域预定义本体的高度依赖使得跨领域迁移成本较高。

Document GraphRAG [20] 从另一个角度切入了文档结构的利用问题。该工作将文档的内在结构——包括标题层级、段落顺序和交叉引用关系——作为知识图谱的一等公民，通过在图中添加结构节点来编码文档组织信息。实验表明，基于文档结构构建的知识图谱在处理需要上下文推理的问题时显著优于纯实体关系图谱，证实了文档内在结构是一种被严重低估的先验知识。不过，Document GraphRAG 仅在图构建阶段引入结构信息，后续的聚类过程仍采用标准的纯拓扑方法，结构信息在社区划分中可能再次被打碎。

DSRAG [21] 则探索了多模态知识图谱在领域特定检索中的应用，通过从文档中衍生融合文本实体、表格数据和图像描述的多模态知识图谱，构建领域感知的检索管线。该工作强调文档衍生知识图谱天然保留了文档级的上下文关联，但其创新集中在图构建阶段的多模态信息抽取，未涉及聚类和层级化组织的改进。

纵观上述专业领域 GraphRAG 的发展脉络，可以提炼出一项重要的跨文献共识：文档的物理组织结构在专业领域知识检索中具有不可替代的语义价值。MedGraphRAG 通过三重图将不同来源的文档显式分离来保持结构信息，SAT-Graph RAG 通过本体建模法律文档的层级结构，Document GraphRAG 通过结构节点编码文档组织关系，DSRAG 通过多模态知识图谱保留文档级上下文。然而，这些工作在领域适配方式上各有侧重——外部标签体系、领域本体、图结构编码或多模态抽取——却共同忽略了一个关键环节：在聚类目标函数层面引入文档物理结构约束。本研究正是从这一未被填补的空白切入，通过在 Leiden 目标函数中嵌入结构熵惩罚项来实现聚类过程中的物理结构保护，同时采用领域无关的物理锚定机制（Chunk_ID / Section_ID / Document_ID）替代对特定领域标签或本体的依赖，以在领域特异性和跨领域泛化性之间取得平衡。

## 2.3 GraphRAG检索策略的演进

GraphRAG 的检索策略经历了从简单到复杂、从单一到多层的持续演进，这一演进路线深刻影响着系统在不同类型查询上的表现。

原始 GraphRAG [1] 采用全社区遍历的检索策略：对于全局性查询，系统遍历所有社区摘要，通过 map-reduce 机制聚合各社区的局部回答以生成全局答案。这一策略虽然保证了全面性，但在大规模图上产生了高昂的 LLM 调用成本和显著的延迟。LightRAG [23] 敏锐地识别到了这一效率瓶颈，提出用双层检索系统——低层聚焦实体和关系的精确信息检索、高层涵盖广泛主题的抽象检索——替代昂贵的全社区遍历。通过引入增量更新机制，LightRAG 在检索质量与效率之间取得了优于原始 GraphRAG 的平衡，但其去除社区结构的设计牺牲了全局语义导航能力。

HiRAG [13] 在层级化检索的维度上迈出了更深入的一步，构建了全局层（Global）、桥接层（Bridge）和局部层（Local）的三级检索架构。桥接层的引入有效解决了纯全局和纯局部检索之间的语义断层问题，使系统能够在不同粒度上捕获查询所需的上下文信息。LeanRAG [11] 则强调了索引与检索的协同设计，在索引阶段通过语义聚合构建层级化知识图谱，并为簇间生成显式的关系描述，避免了传统社区摘要方法中簇间信息割裂的问题。PathRAG [25] 从路径视角重新审视了图检索，通过从索引图中检索关键关系路径并辅以基于流的剪枝算法来减少噪声，在多跳推理查询上展现了优势。NodeRAG [26] 则引入了异构图结构，通过定义多种功能分化的节点类型（高级元素节点、语义单元节点、关系节点等），实现了更精确的层次化检索。

在这条演进路线上，MedGraphRAG 的 U-Retrieval [3] 占据了独特的位置。U-Retrieval 融合了自上而下和自下而上两条检索路径：自上而下从全局文档图沿标签层级逐步缩小检索范围，自下而上从局部三元组匹配向上扩展上下文。这种双轨设计兼顾了全局导航能力和局部精确匹配能力，在医学场景中表现出色。然而，U-Retrieval 的自上而下路径依赖 UMLS 等领域特定的标签体系进行导航，跨领域迁移困难；更重要的是，其自下而上路径在匹配到图节点后，缺乏将节点精确映射回原始文本块的机制——检索到的实体或关系节点无法以 O(1) 的复杂度追溯到其在原始文档中的确切位置，导致微观事实的精确回溯依赖模糊匹配或额外计算。

GraphRAG-FI [14] 从另一个维度揭示了检索策略的挑战：GraphRAG 检索到的知识中存在大量噪声，直接注入反而降低生成质量。该工作通过两阶段过滤机制和 logits 选择策略在外部检索知识与 LLM 内在参数化知识之间实现动态平衡，为所有 GraphRAG 变体提供了关于检索噪声的重要警示。

本研究在检索策略上直接借鉴 MedGraphRAG 的 U-Retrieval 范式，这一设计决策是有意为之的：检索策略本身不构成本研究的创新贡献。本研究的核心价值在于，通过物理锚定机制为 U 型检索的自下而上路径提供了精确的溯源终点——每个图节点携带的物理锚坐标（Chunk_ID, Section_ID, Document_ID）使得节点到原始文本块的追溯成为 O(1) 操作，从而使已有的检索范式在微观事实问题上获得显著更高的回答精度。同时，本研究采用社区摘要层级而非领域标签来支撑自上而下路径，实现了领域无关的全局导航。

## 2.4 Leiden聚类算法与社区检测

Leiden 算法是 GraphRAG 框架的核心组件之一，其聚类质量直接决定了社区摘要的语义连贯性和层级结构的合理性。Traag 等人 [7] 在 Louvain 算法的基础上提出了 Leiden 算法，核心创新在于引入"细化阶段"（refinement phase）：在 Louvain 的"局部移动 + 聚合"两步基础上增加第三步，对每个社区内部的节点重新评估是否应被拆分到子社区，从而保证每个社区的内部连通性。实验表明，Louvain 算法产生的社区中高达 25% 存在内部不连通的缺陷，而 Leiden 算法完全消除了这一问题，同时保持了近线性的时间复杂度 O(m)。然而，Leiden 优化的目标函数——无论是模块度（Modularity Q）还是常数 Potts 模型（CPM）——都是纯拓扑度量，完全不感知节点的外部属性信息。在 GraphRAG 场景中，这意味着来自同一文档章节的强因果证据可能因拓扑连接模式的差异而被分散到不同社区，文档的物理组织逻辑在聚类过程中被打碎。

围绕 Leiden 目标函数的可扩展性，近期的多项工作提供了重要的理论和实证基础。TAS-Com [27] 首次将 Leiden 目标函数嵌入深度学习训练循环，将其作为图卷积网络（GCN）的辅助损失与谱聚类损失进行联合优化。这一工作的核心贡献在于证明了 Leiden 的目标函数可以与其他优化目标共存于同一优化框架中——联合优化策略的效果优于单独使用任一目标函数。Dynamic Leiden-Fusion [28] 从另一个维度扩展了 Leiden 算法，提出增量更新机制和社区融合策略，使 Leiden 能够适用于动态网络的社区检测，在保持社区质量的同时将计算复杂度降低了一个数量级。

与此同时，信息论方法为社区检测提供了坚实的理论基础。Li 和 Pan [8] 提出了网络结构信息和 K 维结构熵的理论框架，建立了结构熵最小化原则（Structural Entropy Minimization Principle, SEP）。K 维结构熵度量的是在给定 K 层编码树下，随机游走者在网络中行走时确定其所在社区位置所需的平均信息量。这一理论的核心优势在于可以自动发现网络的自然层级结构，无需预设社区数量或分辨率参数。结构熵综述 [10] 进一步系统梳理了结构熵理论从生物信息学到模式识别的跨领域应用，展示了其作为通用网络复杂度度量框架的广泛适用性，并指出基于贪心算法和编码树启发式搜索的高效近似方法使结构熵在大规模网络上的实际应用成为可能。

将结构熵理论与社区检测实践相结合的代表性工作是 CoDeSEG [9]。该工作将社区检测建模为势博弈（Potential Game），以最小化二维结构熵作为全局势函数来驱动博弈均衡，在无向图、有向图、加权图和重叠社区四种场景上均展现了竞争力。CoDeSEG 证明了结构熵不仅是一种理论度量，更是一个可操作的社区检测目标函数。在熵优化的参数化扩展方面，基于 Rényi 熵的图聚类工作 [17] 引入了可微的掩码熵损失，通过 Rényi 熵的阶数参数 α 实现对分布尾部敏感度的灵活控制，在聚类质量与计算效率之间取得了优于传统方法的平衡。

综合上述研究进展，可以得出一个关键论断：Leiden 目标函数具有通过附加约束项进行扩展的充分理论和实证基础。TAS-Com [27] 从深度学习角度证明了联合优化的可行性，CoDeSEG [9] 从信息论角度证明了结构熵作为目标函数的有效性，Dynamic Leiden-Fusion [28] 证明了 Leiden 框架本身的可扩展性。然而，迄今为止尚无工作将文档物理结构的信息论度量作为约束项嵌入 Leiden 的目标函数。本研究正是在这一理论基础上提出结构熵约束退火聚类——将基于香农熵的物理结构惩罚项 H_structure 引入 Leiden 目标函数（J = Q_Leiden − λ·H_structure），并通过 λ 的退火调度实现从物理结构保护到语义自由聚合的平滑过渡。值得说明的是，本研究初始阶段选择香农熵而非 Rényi 熵来定义 H_structure，主要出于可解释性强、计算简单和无额外超参数的考虑，但 Rényi 熵的参数化特性为未来的理论扩展保留了清晰的路径。

## 2.5 命题级检索与知识粒度

知识检索的粒度选择对检索质量具有根本性影响。传统 RAG 系统通常以段落或固定长度文本块作为检索单元，但这种粒度选择在面对细粒度事实查询时常常引入过多噪声信息。Chen 等人 [6] 在 Dense X Retrieval 中首次系统性地研究了检索粒度问题，提出了"命题"（Proposition）作为新的检索基本单元。命题被定义为原子化的、自包含的、上下文无关的事实表达——每个命题恰好表达一个独立的事实断言，不依赖外部上下文即可被理解。该工作通过大语言模型将段落分解为命题集合，并构建基于命题粒度的密集向量索引。在五个开放域问答基准上的实验表明，命题级检索在准确性和泛化性上同时优于段落级和句子级检索，证明了更细粒度的检索单元能更精确地匹配查询需求。

命题的"原子化"和"自包含"两个核心特性使其天然适合作为物理锚挂载的基础单元。原子化意味着每个命题对应的事实来源是明确且唯一的——一个命题不会横跨两个文本块；自包含意味着命题携带了理解该事实所需的全部信息，在脱离原始上下文后仍保持语义完整性。在 PhysAnchor-GraphRAG 的框架中，文本块首先经由命题转换被分解为命题集合，每个命题随即继承其来源文本块的物理锚坐标（Chunk_ID, Section_ID, Document_ID），进而被构建为知识图谱中的三元组。这一设计将 Dense X Retrieval 的命题概念从扁平向量索引扩展到了结构化知识图谱，实现了从非结构化检索到结构化溯源的跨越——每个三元组不仅承载语义信息，还通过物理锚保持了向原始文本块的精确回溯能力。

## 2.6 RAG忠实性与溯源评估

大语言模型的幻觉（Hallucination）问题是制约 RAG 系统在专业领域可信部署的核心障碍。关于 LLM 幻觉的综合调查 [16] 将幻觉分为内在幻觉（与训练数据矛盾的生成内容）和外在幻觉（无法从训练数据中验证的生成内容），并指出 RAG 可以有效降低外在幻觉，但对内在幻觉的缓解效果有限。这一分类框架对于界定 PhysAnchor-GraphRAG 的贡献边界具有重要意义：物理锚定机制主要应对的是外在幻觉——因检索证据脱离原始上下文而导致的事实偏差，通过建立"证据-出处"的刚性绑定来确保生成内容有据可查。

在 RAG 忠实性的评估方面，FaithJudge [15] 引入了系统性的基准数据集与动态排行榜，覆盖摘要、问答和数据到文本生成三类任务。该工作揭示了一个令人警醒的发现：当前主流的幻觉检测器（如 HHEM）在实际 RAG 场景下的检测精度远低于预期，存在显著的假阴性问题。这意味着仅依赖后验检测来保障 RAG 系统的忠实性是不够的，更根本的路径应当是从检索源头减少幻觉产生的可能性。GraphRAG-FI [14] 从知识过滤的角度部分回应了这一需求，通过两阶段过滤和 logits 选择策略在外部知识与内在推理之间寻求平衡。Sharma 等人 [18] 在 RAG 架构综述中进一步指出，检索质量、证据融合和生成一致性构成了 RAG 系统可靠性的三大挑战维度，其中知识图谱增强检索在提升检索质量方面仍处于早期探索阶段。

然而，审视现有的 RAG 评测体系可以发现一个重要的维度缺失：现有评测主要关注生成端的忠实性（生成内容是否与检索证据一致）和检索端的相关性（检索结果是否与查询相关），却缺乏对"溯源精度"（Provenance Accuracy）的系统评估——即给定一个回答中的事实断言，系统能否精确追溯到原始文本块中的确切位置。GraphRAG [1] 的评测侧重 Comprehensiveness 和 Diversity，FaithJudge [15] 评估生成忠实性，GraphRAG-FI [14] 关注知识过滤效果，但这些工作均未将溯源精度纳入评测框架。在专业领域中，溯源精度具有不可或缺的实际价值：医生需要知道某一诊断建议源自哪篇文献的哪个段落，律师需要确认某一法律论证引用的是哪部法规的哪一条款，研究者需要验证某一实验结论出处的确切上下文。本研究基于这一观察，提出 Provenance Precision / Recall / F1 评测指标作为现有 RAG 评测体系的补充，以填补溯源精度评估的空白。PhysAnchor-GraphRAG 的物理锚定机制从设计上保证了全链路的溯源能力，使得溯源精度的系统化评测成为可能。

## 2.7 本章小结

本章从六个维度系统梳理了与 PhysAnchor-GraphRAG 相关的研究基础。通过对上述文献的分析，本研究的差异化定位可以从三个维度加以刻画。在信息注入层级维度上，本研究在 Leiden 聚类的目标函数层注入物理结构信息，区别于 ArchRAG [24] 的输入层（LLM 语义嵌入）、GraphRAG-FI [14] 的输出层（后置过滤）和 Document GraphRAG [20] 的图构建层（结构节点），目标函数层是一个未被占据的注入点。在成本-质量权衡维度上，本研究通过算法级修改（目标函数加退火调度）实现聚类质量改进，不引入额外 LLM 调用，区别于 ArchRAG 的高 LLM 成本路线和 MedGraphRAG [3] 的重量级预处理路线。在溯源保障维度上，本研究提出贯穿全链路的物理锚定机制，从图构建到聚类到检索都保持三元组的出处坐标，区别于 Document GraphRAG 仅在构建阶段引入结构信息、GraphRAG 完全无溯源、以及 MedGraphRAG 依赖外部标签的局部溯源方案。这三个维度的交叉形成了 PhysAnchor-GraphRAG 独特的贡献空间。
