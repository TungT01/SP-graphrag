# 第3章 研究框架（上）

## 3.1 问题形式化

本章提出 PhysAnchor-GraphRAG 框架的完整技术方案。在展开具体设计之前，首先对研究问题进行形式化定义，明确输入、输出与优化目标。

**输入。** 设专业领域文档集合为 $D = \{d_1, d_2, \ldots, d_M\}$，其中每篇文档 $d_l$ 具有显式的物理层级结构。文档 $d_l$ 由有序章节序列 $d_l = \langle s_{l,1}, s_{l,2}, \ldots, s_{l,|S_l|} \rangle$ 组成，每个章节 $s_{l,k}$ 进一步由文本块序列 $s_{l,k} = \langle c_{l,k,1}, c_{l,k,2}, \ldots \rangle$ 组成。对文档集合进行分块处理后，得到文本块集合 $X = \{x_1, x_2, \ldots, x_N\}$，每个文本块 $x_i$ 关联一个三元物理位置 $\text{loc}(x_i) = (c_i, s_i, d_i)$，分别对应文本块标识、章节标识和文档标识。在此基础上，通过实体抽取与关系构建，形成知识图谱 $G = (V, E_G)$，其中 $V$ 为实体节点集合，$E_G$ 为关系边集合。

**输出。** 给定用户查询 $q$，系统生成回答 $a$ 并附带溯源集合 $\text{Prov}(a) = \{(c_j, s_k, d_l)\}$，其中每个三元组表示回答中某一事实断言所源自的文本块 $c_j$、章节 $s_k$ 和文档 $d_l$。溯源集合为使用者提供从微观到宏观的三级证据追溯路径。

**优化目标。** 本研究追求三重目标的帕累托均衡：

$$
\max_{\theta} \; \text{Micro-Accuracy}(\theta), \quad \text{s.t.} \quad \text{Macro-Quality}(\theta) \geq Q_{\text{GraphRAG}}, \quad \text{Token-Cost}(\theta) \leq \tau
$$

其中 $\theta$ 为框架的全部可调参数。第一项要求最大化微观事实问题的回答准确率与溯源精度；第二项约束宏观综合问答的质量（全面性、多样性）不低于原版 GraphRAG [1] 的水平；第三项约束查询阶段的 token 消耗远低于将全部文档逐段输入大语言模型的直接方案。三重目标的平衡正是 PhysAnchor-GraphRAG 的设计核心。

为便于后续叙述，统一定义核心符号：$\text{anchor}(e)$ 表示信息元素 $e$ 的物理锚点集合；$C = \{C_1, \ldots, C_K\}$ 为社区划分结果；$Q_{\text{Leiden}}(C)$ 为标准 Leiden 模块度；$H_{\text{structure}}(C)$ 为物理结构熵；$J(C;\lambda) = Q_{\text{Leiden}} - \lambda \cdot H_{\text{structure}}$ 为退火聚类目标函数；$\lambda(t) = \lambda_0 \cdot e^{-\alpha t}$ 为退火调度函数。

## 3.2 框架总览

PhysAnchor-GraphRAG 的整体架构由四个阶段组成，形成从文档输入到带溯源回答输出的完整管线。下图以 ASCII 架构图展示四个阶段及其内部组件，其中★标注的组件为本研究的核心创新。

```
┌──────────────────────────────────────────────────────────┐
│                   PhysAnchor-GraphRAG                      │
│                                                            │
│  ┌───────────────────┐   ┌───────────────────┐            │
│  │ 阶段1：文档预处理   │   │ 阶段2：图构建       │           │
│  │  文档解析           │──→│  命题转换           │           │
│  │  物理结构识别       │   │  实体/关系抽取      │           │
│  │  Chunk 切分         │   │  ★物理锚挂载        │           │
│  └───────────────────┘   └─────────┬─────────┘            │
│                                    │                       │
│                                    ↓                       │
│  ┌─────────────────────────────────────────────┐          │
│  │ 阶段3：★结构熵约束退火聚类                     │          │
│  │  J = Q_Leiden − λ(t)·H_structure               │          │
│  │  H_structure = 香农熵(Section分布)              │          │
│  │  λ(t) = λ₀·e^{−αt}（指数退火）                 │          │
│  │  → 层级社区 + 社区摘要                          │          │
│  └───────────────────────┬─────────────────────┘          │
│                          │                                 │
│                          ↓                                 │
│  ┌─────────────────────────────────────────────┐          │
│  │ 阶段4：U型双轨检索（工程集成）                  │          │
│  │  自上而下：社区摘要匹配 → 范围锁定              │          │
│  │  自下而上：节点匹配 → ★物理锚追溯 → Chunk      │          │
│  │  融合策略 → LLM生成 + 溯源集合                 │          │
│  └─────────────────────────────────────────────┘          │
└──────────────────────────────────────────────────────────┘
  ★ = 本研究的创新组件
```

**阶段1：文档预处理。** 此阶段将原始文档集合 $D$ 转化为结构化的文本块序列。文档解析器首先识别每篇文档的物理层级结构（标题、章节、段落），建立文档—章节—段落的三级树形索引；随后按固定窗口（默认300 tokens）对各章节内文本进行切分，生成文本块集合。每个文本块在生成时即被标记其所属的章节与文档，形成初始物理坐标 $(c_j, s_k, d_l)$，为后续物理锚定机制奠定数据基础。

**阶段2：图构建与★物理锚挂载。** 借鉴 Dense X Retrieval [6] 的命题转换方法，将每个文本块分解为原子化、自包含的命题单元，再通过大语言模型进行实体识别和关系抽取以构建初始知识图谱。在这一过程中，★物理锚挂载作为本研究的第一项创新被嵌入：每个三元组在生成时继承来源命题的物理坐标，多源实体合并时保留所有来源锚点的并集。物理锚挂载是纯元数据操作，不增加任何 LLM 调用，不引入新的图节点，也不改变图的拓扑结构。

**阶段3：★结构熵约束退火聚类。** 此阶段是本研究的核心算法创新。标准 GraphRAG [1] 使用 Leiden 算法 [7] 优化纯拓扑目标函数 $Q_{\text{Leiden}}$。本研究将目标函数修改为 $J = Q_{\text{Leiden}} - \lambda(t) \cdot H_{\text{structure}}$，其中 $H_{\text{structure}}$ 为基于香农熵 [8] 的物理结构混杂度度量，$\lambda(t)$ 为指数退火调度函数。退火过程实现了从早期物理结构保护到后期语义自由连接的平滑过渡。聚类完成后对各社区生成摘要，形成层级化的社区—摘要索引。

**阶段4：U型双轨检索（工程集成）。** 此阶段借鉴 MedGraphRAG [3] 的 U-Retrieval 范式与 HiRAG [13] 的层级检索策略，不构成本文的创新贡献。自上而下路径从社区摘要出发锁定目标范围；自下而上路径从实体节点出发，通过★物理锚追溯到原始文本块，实现 $O(1)$ 精确溯源。两条路径的检索结果经融合后输入 LLM 生成最终回答，同时输出溯源集合 $\text{Prov}(a)$。

四个阶段之间的数据流单向串行：阶段1输出流入阶段2，阶段2输出流入阶段3，阶段3与阶段2的图结构共同流入阶段4。这一管线设计保证了物理锚信息在全链路中的完整传播——这正是3.3节将详细论证的关键性质。

## 3.3 物理锚定机制（★创新1）

物理锚定机制是 PhysAnchor-GraphRAG 的基础性创新，其核心思想是：为知识图谱中的每一个信息元素附加一组不可丢失的物理出处坐标，使得无论图结构经历何种变换，任意信息元素都能在 $O(1)$ 时间内追溯到其在原始文档中的精确位置。

### 3.3.1 三级物理锚点定义

**定义1（物理锚点）。** 对于知识图谱中的任意信息元素 $e$（三元组、实体节点或社区节点），其物理锚点集合定义为：

$$
\text{anchor}(e) = \{(c_j, s_k, d_l) \mid e \text{ 的信息源自文档 } d_l \text{ 的章节 } s_k \text{ 中的文本块 } c_j\}
$$

三元组的三个分量分别对应文本块级（Chunk）、章节级（Section）和文档级（Document）三个物理粒度。文本块级提供最精细的事实定位，章节级提供因果上下文的边界，文档级提供全局来源标识。三级粒度共同构成从微观到宏观的完整溯源路径。

物理锚点具有三个关键的"零成本"性质：（1）不增加 LLM 调用——锚点信息在文档预处理阶段即可确定，无需额外的大语言模型推理；（2）不引入新的图节点或边——锚点存储为节点的属性字段而非独立实体；（3）不改变图的拓扑结构——锚点的存在与否不影响节点间的连接关系。这三个性质保证了物理锚定机制的零边际推理成本特性。在存储开销方面，每个锚点三元组仅需3个 ID 字段（约12字节），总存储开销约为原始图结构存储量的15%—25%，在工程上完全可接受。

### 3.3.2 命题转换中的锚点继承

在图构建阶段，原始文本块 $c_j$ 首先经过命题分解（Proposition Decomposition）[6] 生成一组原子化命题 $\{p_1, p_2, \ldots, p_n\}$。每个命题是一个自包含的事实陈述，满足"去上下文化"条件，即脱离原始段落仍可独立理解。

物理锚点按以下继承规则传播：

**规则1（命题锚点继承）。** 若命题 $p_i$ 由文本块 $c_j$ 分解而来，则 $\text{anchor}(p_i) = \text{anchor}(c_j) = \{(c_j, s_k, d_l)\}$。

由于每个命题源自且仅源自一个文本块，继承关系是一对多的确定性映射（一个文本块可生成多个命题，但每个命题只有一个来源），因此继承规则不存在歧义。随后，对命题进行实体识别和关系抽取，将每个命题转化为一组三元组 $(h, r, t)$。三元组同样继承其来源命题的物理锚点：若三元组 $(h, r, t)$ 从命题 $p_i$ 中抽取，则 $\text{anchor}((h, r, t)) = \text{anchor}(p_i)$。这一继承链确保了从原始文本到知识图谱三元组的物理溯源信息不在任何环节断裂。

### 3.3.3 实体合并中的多源锚点保留

同一实体可能在不同文档的不同章节中被多次提及，形成多个独立的实体节点。实体对齐（Entity Resolution）阶段需要将这些重复节点合并为单一节点。合并操作是物理锚点面临的首个挑战：如何在合并后保留所有来源的溯源信息？

**规则2（合并锚点并集）。** 当多个来源的实体被合并为同一节点 $v$ 时，合并节点的锚点集合取所有来源锚点的并集：

$$
\text{anchor}(v) = \bigcup_{e \in \text{sources}(v)} \text{anchor}(e)
$$

以一个具体场景为例：若实体"白细胞介素-6"分别在文档 $d_1$ 的"方法"章节和文档 $d_3$ 的"结果"章节中被提及，则合并后节点的锚点集合包含两个来源的物理坐标，即 $\text{anchor}(v) = \{(c_{12}, s_{1,2}, d_1),\; (c_{47}, s_{3,4}, d_3)\}$。

合并操作导致的锚点集合膨胀需要评估。设知识图谱中共有 $|V|$ 个节点，平均每个节点由 $\bar{m}$ 个来源实体合并而成。在典型的专业领域知识图谱中，$\bar{m}$ 的中位数通常为1—3（大多数实体仅在少数文档中出现），少数高频实体可达10—20。据此估算，锚点元数据的额外存储开销约为原始图结构存储量的15%—25%，符合轻量化的设计目标。

### 3.3.4 物理锚在图结构演化中的传播保证

物理锚定机制的核心价值在于其全链路传播保证：无论知识图谱经历何种结构变换，物理锚信息只增不减。下面以命题形式给出形式化陈述与证明。

**命题1（锚点传播单调性）。** 对于任意图变换操作 $T$（包括实体合并、社区合并和层级压缩），若输入图 $G$ 中信息元素 $e$ 具有锚点集合 $\text{anchor}(e)$，则输出图 $T(G)$ 中对应元素 $e'$ 的锚点集合满足：

$$
\text{anchor}(e) \subseteq \text{anchor}(e')
$$

**证明。** 采用对图变换操作的归纳法。

*基础情形（实体合并）。* 设节点 $v_1, v_2, \ldots, v_n$ 被合并为节点 $v'$。根据规则2，$\text{anchor}(v') = \bigcup_{i=1}^n \text{anchor}(v_i)$。对于任意 $v_i$，显然有 $\text{anchor}(v_i) \subseteq \bigcup_{i=1}^n \text{anchor}(v_i) = \text{anchor}(v')$，单调性成立。

*归纳步骤（社区合并与层级压缩）。* 社区合并将社区 $C_k$ 中的节点集合 $\{v_1, \ldots, v_{|C_k|}\}$ 聚合为超节点 $u_k$，定义 $\text{anchor}(u_k) = \bigcup_{v \in C_k} \text{anchor}(v)$。对于任意 $v \in C_k$，$\text{anchor}(v) \subseteq \text{anchor}(u_k)$，单调性成立。层级压缩是社区合并的递归应用——将底层超节点进一步聚合为更高层的超节点。由归纳假设（社区合并保持单调性）和集合并运算的结合律，递归应用后单调性仍然成立。

综合以上情形，命题1得证。 $\square$

命题1的实际意义在于：在 PhysAnchor-GraphRAG 的完整处理管线中，从文本块经命题分解、实体抽取、实体合并、社区聚类到层级压缩的每一步，物理锚信息都只会增加或保持不变，绝不会丢失。这为检索阶段的精确溯源提供了理论保障——无论查询命中的是底层实体节点还是高层社区摘要节点，都可以通过读取其锚点集合在 $O(1)$ 时间内直接定位到原始文本块，无需额外的模糊匹配或反向搜索。
